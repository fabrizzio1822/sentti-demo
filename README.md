# Sentti · Demo de joyería

Propuesta visual local independiente de CRM HUNTER. Next.js, React, TypeScript y Tailwind CSS.

## Ejecutar

```sh
npm install
npm run dev
```

Abrir http://localhost:3001. Producción: `npm run build` y `npm start`.

Incluye filtros, búsqueda, detalle de producto, favoritos, bolsa con cantidades (máximo 20 por producto), persistencia local y formulario de suscripción simulado. Sin servidor comercial, cobros, envíos de correo ni pedidos reales. El catálogo, nombres y textos son ilustrativos; no representan productos ni condiciones confirmadas por Sentti. No se han inventado precios, reseñas, garantías o promociones.
